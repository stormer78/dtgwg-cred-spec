[[def: M-DID, membership DID, M-DIDs]]

~ **Retired as a normative type.** Informal shorthand for the identifier a member asserts to a [[ref: VTC]]. Normatively it is an identifier whose declared [[ref: correlation scope]] is `community` when it is used with one community, or `linked` when the member deliberately asserts the same identifier across several so as to be correlated between them. **Membership is conferred by the [[ref: VMC]] pair, not by the identifier**: the community-issued VMC is issued to this identifier and the member acknowledges it from the same one. That machinery is unchanged; only the claim that the identifier is a distinct *type* is retired — it is what made an identifier appearing in both a VMC and a VRC ambiguous.
